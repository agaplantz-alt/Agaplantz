## Claude Ads

This repo enables the [Claude Ads](https://github.com/AgriciDaniel/claude-ads)
Claude Code plugin via `.claude/settings.json`. See
[docs/claude-ads-setup.md](docs/claude-ads-setup.md) for install, verification,
and removal steps.

## Claude Video Vision

This repo also enables the
[Claude Video Vision](https://github.com/jordanrendric/claude-video-vision)
plugin, which lets Claude watch video files and YouTube links. See
[docs/claude-video-vision-setup.md](docs/claude-video-vision-setup.md) for
install, backend configuration, verification, and removal steps.
