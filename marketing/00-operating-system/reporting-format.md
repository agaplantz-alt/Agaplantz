# Reporting Format (PART 21)

Analysis output uses this structure. No 50-page theory dumps.

```
WHAT IS WRONG      Most important problems, ranked.
WHY IT IS HAPPENING  Evidence-based diagnosis. Label fact / inference / hypothesis.
WHAT WE SHOULD DO   Specific actions, not principles.
PRIORITY           Critical / High / Medium / Low
EXPECTED IMPACT    Estimate + the reasoning behind it.
RISK               Low / Medium / High
IMPLEMENTATION     Exactly how to execute.
MEASUREMENT        Exact metrics, baseline, and read date.
```

**Rules**
- Lead with the problem, not the methodology.
- Quantify impact in dollars where possible; show the arithmetic.
- If a recommendation rests on an assumption, say so in the same sentence.
- Always state what you could not determine.
